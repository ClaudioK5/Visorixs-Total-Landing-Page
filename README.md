# Visorix Landing Page

General product landing page for **Visorix** — an AI assistant for understanding and working with video.

CTAs → [app.visorix.tech](https://app.visorix.tech)

Routes:

- `/` — general landing page
- `/podcasters` — podcaster landing page
- `/creators` — creator landing page

## Develop

```bash
npm install
npm run dev
```

## Edit

- Product name, app URL, CTA text → `src/config/site.ts`
- Section copy → `src/content/copy.ts`
- Screenshots → `public/screenshots/` and `src/assets/`
